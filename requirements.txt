# ── PyTorch — pinned to a CUDA 12.x build (works on driver >= 525 / CUDA 12.x) ──
# NOTE: unpinned `torch>=2.5` resolves to the newest cu13x wheel, which fails on the
# common CUDA 12.x drivers (torch.cuda.is_available() == False). Newer GPUs (e.g.
# Blackwell) may need a newer cu12x/cu13x build — adjust the version + index to match
# your driver (see https://pytorch.org). Verify after install:
#   python -c "import torch; print(torch.cuda.is_available())"
--extra-index-url https://download.pytorch.org/whl/cu121

# and mismatches here tend to segfault rather than raise — same class of issue as the
